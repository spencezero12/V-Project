Sistema operativo independiente tipo UNIX inspirado en Void Linux y runit para CC:Tweaked (Minecraft 1.20.1 Fabric).

-Kernel monolítico modular con aislamiento de entorno `_ENV`.
-Planificador cooperativo basado en corrutinas.
-Sistema de archivos virtual (VFS) independiente con nodos-i (inodos).
-Supervisor de procesos en tres etapas inspirado en `runit`.
